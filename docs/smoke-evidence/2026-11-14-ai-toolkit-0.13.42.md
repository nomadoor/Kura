named by SHA; upstream has no Git tags, so versions come from `version.py`.

The registered arch set grows from 60 to 65 (`fibo2`, `minimax_h3_image`,
`minimax_h3_omni`, `p_h3_image`, `qwen38`); 54 model classes import in the new
image (`2026-11-14-ai-toolkit-0.13.42-class-import.yaml`). The regenerated
baseline adds exactly those five entries and changes none of the existing 64.
`jobConfig.ts` and `data_loader.py` are unchanged.
